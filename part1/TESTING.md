# Part 1: generate the two authentic strace files

On a Linux host/VM with gcc and strace:

```sh
sudo apt install -y strace gcc make     # if not already installed
cd ~/elevator/part1
make verify
```

`make verify` compiles both programs and generates `empty.trace` and
`part1.trace`, then checks for exactly five additional system call lines.
It is important to trace BOTH executables on the **same host** with the
same `strace` installation. These traces are not part of this handoff ZIP
because they must be generated by your own Linux environment. Commit the
`.trace` files to GitHub once you have verified the five-call difference.
Do not commit the `empty` or `part1` executables.
